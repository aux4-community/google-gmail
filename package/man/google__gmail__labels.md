#### Description

The `google gmail labels` command group works with the labels in the mailbox of the authenticated account. Labels are how Gmail organizes messages — both the system labels (`INBOX`, `SENT`, `UNREAD`, `STARRED`, `TRASH`) and any custom labels you have created.

Available subcommands:

- **list** — List all labels in the mailbox with their IDs

#### Usage

```bash
aux4 google gmail labels <subcommand>
```

#### Example

```bash
aux4 google gmail labels list
```
